# Description Style Guide

## Setting Description

### Show, Don't Tell Principle
- Use specific, concrete details instead of abstract descriptions
- Filter descriptions through character perspective and emotional state
- Avoid information dumps; weave setting details into action and dialogue

### Sensory Details
- Include multiple senses, not just visual
- Use sensory details that serve the story mood and character state
- Avoid overwhelming readers with excessive description

## Character Description

### Physical Appearance
- Introduce key physical details gradually throughout scenes
- Focus on distinctive features that serve character development
- Avoid detailed physical inventories; select meaningful details

### Emotional Description
- Show emotions through physical reactions and behavior
- Use body language and micro-expressions
- Avoid naming emotions directly; let readers infer from actions

## Action Description

### Movement and Action
- Use active voice for dynamic scenes
- Keep action descriptions clear and easy to follow
- Balance detail with pacing requirements

### Dialogue and Action Integration
- Weave action beats into dialogue naturally
- Use action to break up long dialogue exchanges
- Ensure action beats serve character development or plot advancement
