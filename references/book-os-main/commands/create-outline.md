# Create Outline

Create a detailed story outline for a new novel with character development and scene breakdown

## IMPORTANT EXECUTION INSTRUCTIONS

1. **First, determine the user profile path**:
   - On Windows: Run `Bash(echo $USERPROFILE)` 
   - On macOS/Linux: Run `Bash(echo $HOME)`

2. **Then read the workflow file**:
   - Replace `~` with the actual user profile path obtained above
   - Read the file at: `[USER_PROFILE_PATH]/.novel-os/instructions/core/create-outline.md`
   - Example: `C:\Users\Sonny\.novel-os\instructions\core\create-outline.md` (Windows)
   - Example: `/home/username/.novel-os/instructions/core/create-outline.md` (Unix)

3. **Execute the complete workflow** from the create-outline.md file

## Prerequisites

- Novel-OS must be installed globally at `[USER_PROFILE_PATH]/.novel-os/`
- Project must have been initialized with `/plan-novel` (`.novel-os/novel/` exists)
