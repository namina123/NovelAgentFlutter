# Changelog

All notable changes to Novel-OS will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-08-18

### Added
- **Initial Release** - Complete Novel-OS framework for AI-assisted novel writing
- **Core Instruction Files**:
  - `plan-novel.md` for novel project initialization
  - `create-outline.md` for story structure planning
  - `write-scenes.md` for scene writing coordination
  - `write-scene.md` for individual scene writing
  - `analyze-manuscript.md` for existing manuscript analysis
- **Writing Standards**:
  - `writing-style.md` for narrative voice and prose guidelines
  - `narrative-techniques.md` for story structure and character development
  - Genre-specific guides for literary fiction, mystery/thriller, and fantasy/sci-fi
- **Specialized Subagents**:
  - `context-researcher.md` - Information retrieval and research support
  - `manuscript-creator.md` - File creation and template application
  - `writing-workflow.md` - Version management and backup operations
  - `prose-reviewer.md` - Quality review and style consistency checking
  - `continuity-checker.md` - Story continuity and character consistency analysis
  - `date-checker.md` - Date determination for folder naming
- **Novel Project Structure**:
  - Novel documentation framework (premise, writing plan, decisions)
  - Manuscript organization system (outlines, character profiles, world-building)
  - Task management for scene-by-scene writing workflow
- **Setup Scripts** for easy installation with Claude Code and Cursor
- **Integration** with AI coding assistants adapted for creative writing
- **Writing Task Management** with structured creative workflow
- **Story Planning** and organization system

### Novel-OS Features
- **Three-Layer Context System**: Standards, Novel, and Manuscripts for complete creative context
- **Structured Writing Workflow**: From premise to published manuscript
- **Character Consistency Tracking**: Maintain character voice and development arcs
- **Plot Continuity Checking**: Identify and resolve story inconsistencies
- **Genre-Specific Guidelines**: Tailored advice for different fiction genres
- **Version Control for Manuscripts**: Track drafts, revisions, and writing progress
- **AI-Assisted Quality Review**: Automated prose review and style consistency checking
