# 章节起草法

## 使用时机

在以下场景触发：

1. 已有章纲，需要展开为章节正文。
2. 用户要求写样章、补写场景或续写某一段。
3. 需要把结构层内容转成真实阅读体验。

## 工作流程

### 第一步：抓住本章任务

先明确本章最重要的三个问题：

1. 这一章要推进什么
2. 这一章的主要阻力是什么
3. 这一章结束后，局势发生了什么变化

如果这三点不清楚，正文很容易散。

### 第二步：按场景推进，而不是按说明推进

优先让每个场景承担明确作用：

1. 建立局势
2. 引入冲突
3. 提高代价
4. 给出阶段性结果或反转

不要把章纲条目直接抄成说明文。

### 第三步：控制节奏与视角

一章内部先保证：

1. 视角稳定
2. 场景连接清楚
3. 情绪递进自然
4. 关键信息的揭示顺序合理

在这些成立之后，再考虑语言修饰。

## 约束

1. 未确认正文仍应明确标注为待确认内容，不要冒充最终定稿。
2. 修订旧稿时，先读取原文再局部改写。
3. 没有工具时也能直接输出完整正文；有项目写入能力时，完整章节写入 chapters/，局部场景写入 scenes/。
4. 不要为了“热闹”额外加入会破坏长期设定的桥段。
