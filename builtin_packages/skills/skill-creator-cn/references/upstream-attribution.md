# Upstream Attribution

本内置技能基于 `references/skill-creator-cn-main` 中的中文 Skill Creator 资料整理与改写。

用户已说明其上游采用 Apache 2.0 许可，因此本项目在内置该技能时保留来源说明，并将内容重组为更适合 Novel Agent 的技能包结构。

本内置版本的主要调整：

1. 改为项目内统一的标准 `SKILL.md` 包结构。
2. 增加“能力依赖而非工具硬绑定”的约束。
3. 增加可由 Dart 运行的初始化、验证、打包脚本版本。
4. 保留中文工作流指导，但让结构更适合作为内置技能长期维护。
