# 大纲生成

## 使用时机

在以下场景触发：

1. 用户要先有整体结构再继续写作。
2. 现有想法很多，但主线和阶段关系混乱。
3. 需要把总纲细化成卷纲或章纲。

## 工作流程

### 第一步：确认大纲层级

先判断当前更适合输出哪一层：

1. 总纲：全书主线、终局方向、阶段冲突
2. 卷纲：一卷的目标、变化、阶段高潮
3. 章纲：单章任务、场景目标、关键事件

不要把三层信息混成一张平铺列表。

### 第二步：先搭骨架再补充细节

优先明确：

1. 主角要什么
2. 为什么现在得不到
3. 冲突如何升级
4. 哪些转折会改变局势
5. 哪一步会把故事推向下一阶段

### 第三步：保持结构可扩展

每一层只写足够支撑下一步创作的关键信息。不要把正文细节、长对白和即兴桥段塞进大纲层。

## 约束

1. 世界规则如果会限制剧情，必须提前写进结构。
2. 关键转折要和角色动机、代价、后果连起来。
3. 没有工具时直接输出结构化大纲；有项目写入能力时再落到对应目录。
4. 如果信息不足，先保守搭骨架，不要凭空写死长期设定。
