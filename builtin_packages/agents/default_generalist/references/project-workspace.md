# Project Workspace Guide

该参考资料用于提醒默认智能体如何理解 Novel Agent 项目目录。

## 核心原则

1. `drafts/` 放未确认正文、样章和工作草稿。
2. `chapters/` 只放确认后的正式正文。
3. `outline/`、`volume_outlines/`、`chapter_outlines/` 分别对应不同层级的大纲。
4. `world/`、`characters/`、`summaries/`、`tasks/`、`reviews/` 保存长期结构化信息。

## 读写边界

1. 读取前先判断是否真有必要。
2. 修改已有文件前优先先读原文。
3. 重要覆盖、恢复和删除动作优先先备份。
